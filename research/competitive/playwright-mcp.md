## 阅读边界

- 核对日期 2026-10-25；未运行仓库代码或竞品基准。
- 固定 MCP 工具按该 SHA 的 README 全量枚举；配置项单列，不将配置项数当工具数。
- 依赖的 playwright-core 版本为 1.64.0-alpha-1790635538000，其 npm gitHead 为 e8149b8257d32dcf8f72573ecc43e72439da7080。
- 已核对单独 README、配置声明、嵌入导出、底层工具过滤与关键实现；没有将 Playwright 通用 API 或兄弟 CLI 的能力全部视为本 MCP 原生功能。
- 动态页面 WebMCP 工具不能静态穷举，名称模式单列；skillOnly 内部固定工具不冒充公开固定 MCP。
- 未证实表示已查范围不足以确认合同，不等于该功能不存在；未提供仅指本次完整固定 MCP 目录未暴露对应正式接口。
- 72 个固定 MCP 工具是核心与所有可选能力组的目录并集，不代表默认全部启用；124 接口还包含配置项、SDK 与动态名称模式。
