## 阅读边界

- 核验日期：2026-10-25（Asia/Shanghai）。元仓库默认分支 main；其 SHA 不是完整产品源码的唯一版本。
- 同日核验组件 HEAD：UI 46b45fda825d60773b9c4c1d31ef493170786bce；server 3973d10b7ae8d67632dd6105ee9c70c867baf0ac；desktop 71c10c78abe09bdb025063b28025f5c65bc6812c；Mockttp cfe8cb046996390723433c67830602d0cd2dd8bc。官方说明 server 会后台更新，不能把这几个 HEAD 都声称包含在桌面 v1.27.3 安装包。
- MCP/ctl 和 SSE 事件展示以当前官方源码为依据；官网旧页面未列全这些新入口。MCP 是官方实现，不能据旧印象标为没有。
- MCP 免费层有每会话/正文大小额度；规则操作、自动接入激活等定义为 Pro。没有运行安装包验证当前账号或分发渠道的可用性。
- 常规抓包查看和手工断点免费；自动规则、导入导出、配置和部分重发为 Pro。付费分层描述预构建产品，不表示相关源代码未开放。
- 代理核心、UI、interceptors 是不同组件；Mockttp SDK 可编程能力不自动等价为 HTTP Toolkit 所有 UI/MCP 工具均已开放。
- Android/iOS 的部分可选接入标为实验性且有设备要求；只列高层能力，不提供修改应用或绕过安全保护的操作方法。
- 浏览器启动用于接入抓包，不是已提供任意页面点击、ARIA/ref 或多步业务 Agent；保留这种范围差异。
- 未实测连接开放时压缩 SSE 的增量事件链路；当前找到的 parser 接收完整 text 并格式化，不能由此推断有持久事件游标。
- 官方价格页将 Team workspaces 标为 coming soon，本次不记为已交付协作能力。
- 机器操作目录共有12个operation定义，并非同一时刻暴露12个工具：ready状态免费账号8个、Pro账号11个（account.upgrade仅免费）；start_httptoolkit/diagnose_httptoolkit_connection只在没有operation可用且满足条件时出现，不额外加到ready工具数。
- 接入方式的18行是合并浏览器渠道与manual UI路径的产品分组；后端buildInterceptors精确注册25个对象，以下接口目录另外逐类列出，二者不是同一个计数口径。
- 补充固定源码证据：HttpBody._runDecode先等待body不再streaming，再Buffer.concat和decodeBody；本报告所审UI/MCP正文读取管线没有开放压缩SSE增量解码，流结束或aborted后才解码，不能将SSE文本展示算作此能力。此结论不否定独立Mockttp库的流式扩展接口。
