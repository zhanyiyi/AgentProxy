# Stagehand：完整公开功能与接口清单

核对日期：2026-10-25。本文按下述源码和官方文档快照整理；不是运行成功率或性能测试。

- 仓库：[https://github.com/browserbase/stagehand](https://github.com/browserbase/stagehand)
- 固定源码：`8023f34161d650c196dc343d2c232fb5e129a826`
- 版本边界：4.0.0（当前monorepo package.json；v3兼容文档不等同当前API）
- 授权边界：MIT
- 清单规模：49 个功能分组、179 个具名接口/配置/协议条目、106 个统一维度。条目粒度不同，不用数量排名。
- [返回横向总表](../../COMPETITIVE_ANALYSIS.md)；[机器可读原始记录](stagehand.json)。

## 阅读边界

- 固定HEAD读取v4所有公开reference、完整docs导航、配置/缓存/部署/集成文档和同仓browse CLI；没有安装运行竞品。
- 最关键版本变化：4.0.0已移除v3 agent()，旧references/agent文档仍留在仓库，不能作为v4当前功能。
- v4正式API面为TypeScript/Python/Go；方法列表以TypeScript名字去重，Python snake_case及Go等价名见各参考，不逐个别名重复计数。
- 浏览器运行时是扩展service worker，Page.on为通用CDP事件订阅；没有据此推定已提供SSE事件持久存储、Heap诊断等成品能力。
- Browserbase Gateway、缓存、Fetch/Search、Functions和云Dashboard均单列云端；具体套餐限制未证实处不猜测付费档。
- 同仓browse CLI是独立可选产品面；其网络落地文件不等于Stagehand SDK自身提供持久数据库。
- 抽取计数：features为有意义的产品能力；interfaces为具名公开操作，SDK方法、HTTP方法+路径、MCP工具、CLI命令和工作流块分别保留类别；不展开每个参数、结果字段、语言别名或底层通用协议全集。接口分组计数：{"Browserbase云端附加服务": 2, "WebMCP/事件订阅": 4, "v4 Response API": 16, "v4 clipboard API": 6, "v4 context API": 12, "v4 locator API": 19, "v4 page API": 29, "v4 stagehand API": 7, "同仓CLI：Cloud": 20, "同仓CLI：Functions": 4, "同仓CLI：交互": 14, "同仓CLI：会话": 3, "同仓CLI：导航": 4, "同仓CLI：技能": 4, "同仓CLI：标签页": 4, "同仓CLI：模板": 3, "同仓CLI：网络": 5, "同仓CLI：观察": 14, "实验MCP适配器": 3, "浏览器工厂与扩展": 6}
- 106项横向维度全部有状态与证据；“未证实”表示查阅上述范围仍缺明确合同，“不适用”表示定位之外，均不按缺少README描述判断为没有。可选集成、官方托管云和内置能力已分开；没有实测性能结论。
