# Chrome DevTools MCP：完整公开功能与接口清单

核对日期：2026-10-25。本文按下述源码和官方文档快照整理；不是运行成功率或性能测试。

- 仓库：[https://github.com/ChromeDevTools/chrome-devtools-mcp](https://github.com/ChromeDevTools/chrome-devtools-mcp)
- 固定源码：`ada7963246c0c91eae185125a57aecd13cbe0376`
- 版本边界：1.12.0（package.json；正式发布 chrome-devtools-mcp-v1.12.0 于 2026-10-22）
- 授权边界：Apache-2.0
- 清单规模：36 个功能分组、178 个具名接口/配置/协议条目、106 个统一维度。条目粒度不同，不用数量排名。
- [返回横向总表](../../COMPETITIVE_ANALYSIS.md)；[机器可读原始记录](chrome-devtools-mcp.json)。

## 阅读边界

- 核对日期 2026-10-25；仅阅读官方文档/源码，未运行竞品。
- 公开 MCP 标准目录、Slim 目录、所有配置开关和可生成 CLI 命令分别枚举；接口条数不可直接当能力排名。
- CLI 描述与生成器有细节差异：fill_form、wait_for、Slim 和隐藏开关工具不生成 CLI，已依源码标注。
- 默认 categoryMemory=true 不代表所有内存分析默认开放；take_heapsnapshot 与 memoryDebugging 条件分析工具分开。
- Chrome 版本门槛、PWA pipe 限制、运行时热更新边界均以固定配置文档为准。
- 包 Node 运行约束：{'node': '^20.19.0 \|\| ^22.12.0 \|\| >=23'}。
- 完整目录之外的隐藏内部工具不作为已发布功能；未证实不等于不存在。
- 60 个标准 MCP 工具是默认与可选类别/条件工具的目录并集，不代表默认全部启用；3 个 Slim 工具属于替代模式，178 接口还包含 CLI 和配置项。
