## 阅读边界

- 只读资料核验日期：2026-10-25（Asia/Shanghai）。默认分支 main；HEAD 为记录的 SHA，不把最新发布标签等同于此 HEAD。
- 功能范围是官方项目及其内置 addons。第三方 MCP 包装、安全扫描脚本或上游库的潜在能力均不算原生功能。
- stable 文档为可变页面；源码证据固定到记录的 commit。源码与文档对 HTTP/1 trailers、streamed body 等描述可能有差异，矩阵保留公开限制，未做实测。
- mitmproxy 是 AgentProxy 的底层依赖。它支持的全部代理模式、协议、内容视图和 UI，不能直接算成 AgentProxy 已开放的 MCP 产品能力。
- 浏览器业务流程、模型规划与页面元素引用属于本项目定位以外；HTTP 重放明确区别于浏览器动作恢复。
- mitmweb 自带 HTTP/WebSocket 路由属于 Web UI 实现接口，本报告不把它表述为保证向后兼容的公共 REST SDK。
- 只读固定 SHA，未运行下载代码或测试。
- default_addons() 精确 31 项，已全部列出；默认加载 addon 不代表其可选行为默认开启。
- 另列17项辅助或前端专用 addon，区别于默认31项。辅助 ServerSideEvents 仅警告，不是 SSE 事件解析器。
- ProxyMode 支持9个可运行模式；osproxy为明确拒绝的旧别名，Http3Mode仅注释。HTTP/3 可用范围应结合 reverse/local/WireGuard 等模式和协议文档，不宣称 regular 直接提供 HTTP/3。
- 命令目录来自 addons/*.py、consoleaddons.py 与 keymap.py 中公开 @command.command 的固定名称；用户 addon 动态注册命令不能静态穷举。
- 未枚举所有 option 参数和 Web REST 路由
