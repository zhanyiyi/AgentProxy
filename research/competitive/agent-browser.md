- 仓库：[https://github.com/vercel-labs/agent-browser](https://github.com/vercel-labs/agent-browser)
- 固定源码：`372ac5ce20fab885dbf45ee0c9d510ec8c3b6fdb`
- 版本边界：0.39.2（package.json；正式发布 v0.39.2 于 2026-10-22）
- 授权边界：Apache-2.0
- 清单规模：50 个功能分组、393 个具名接口/配置/协议条目、106 个统一维度。条目粒度不同，不用数量排名。
- [返回横向总表](../../COMPETITIVE_ANALYSIS.md)；[机器可读原始记录](agent-browser.json)。

## 阅读边界

- 核对日期 2026-10-25；只读官方源码/文档，未运行下载代码、浏览器或性能基准。
- 156 个固定 MCP 是所有能力组的目录并集，默认 core 为 29；CLI 命令、别名、配置和插件协议另行列出，不能用总接口数排名。
- 工具定义与常量 156 项逐项对齐；具体参数见固定 mcp.rs 的 schema，不复制整段 upstream 描述。
- 浏览器视口 WebSocket 不是网站应用 WebSocket 捕获；实时 Console 与活动流也不是持久证据库。
- 旧 TypeScript/Playwright daemon 已移除；streaming 文档保留的 TypeScript 片段未视为本版本受支持 SDK 证据。
- 多引擎、iOS、WebGPU、云提供方和插件存在不同依赖/限制；Cloud/Gateway 费用与服务条款在外部，本体开源不代表外部服务免费。
- 默认自动取消部分 alert/beforeunload；正常 confirm/prompt 和显式 dialog 工具语义应按具体页面读取。
- 未证实不是不存在；未提供仅针对本次完整公开 CLI/MCP 目录缺少相应专用接口，不否认外部脚本可自行实现。
